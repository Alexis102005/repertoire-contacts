# Répertoire de Contacts

Un gestionnaire de contacts en ligne de commande développé en C.

## Fonctionnalités
- Ajouter un contact
- Rechercher un contact
- Modifier un contact
- Supprimer un contact

## Compilation
```bash
make
```

## Utilisation
```bash
./repertoire
```

## Technologies
- Langage : C
- Base de données : SQLite (à venir)
